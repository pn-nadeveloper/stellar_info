## 🚀 Getting Started
### 요구 사항
- Node.js

### Installation
1. Clone the repo
   ```sh
   git clone https://github.com/username/project.git
   ```
2. Install packages
   ```sh
   yarn install
   ```
3. Run
   ```sh
   yarn start
   ```
