## 🚀 Getting Started
### 요구 사항
- Node.js

### Installation
1. Clone the repo
   ```sh
   git clone https://github.com/pn-nadeveloper/stellar_info.git
   ```
2. Install packages
   ```sh
   npm install
   ```
3. Run
   ```sh
   node stellar_info.js
   ```

## 🛠 사용방법
- api/stellar/all : 전체 멤버 정보 호출
- api/stellar/everys : 에버리스 멤버 정보 호출
- api/stellar/universe : 유니버스 멤버 정보 호출
- api/stellar/cliche : 클리셰 멤버 정보 호출
- api/stellar/mystic : 미스틱 멤버 정보 호출
- api/stellar/yuni : 유니 정보 호출
- api/stellar/huya : 후야 정보 호출
- api/stellar/hina : 히나 정보 호출
- api/stellar/mashiro : 마시로 정보 호출
- api/stellar/lize : 리제 정보 호출
- api/stellar/tabi : 타비 정보 호출
- api/stellar/shibuki : 시부키 정보 호출
- api/stellar/rin : 린 정보 호출
- api/stellar/nana : 나나 정보 호출
- api/stellar/riko : 리코 정보 호출
